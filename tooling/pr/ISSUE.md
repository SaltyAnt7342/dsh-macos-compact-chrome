# [Feature] macOS 桌面端侧栏紧凑化，并提供经典布局切换

## 现状

macOS 桌面展开态侧栏在列表前占用约 310px：52px 窗栏、48px 品牌行、48px 新会话、120px 三行面板（插件 / 自动化任务 / 更多）、42px 工作区头。默认窗口 1280×820 下，列表可用高度约 402px。

## 建议

- 把品牌标与名称收进 52px 窗栏，删除品牌行。
- 把三行面板改为单行工具条图标，与新建会话同排。
- 保留工作区树、会话字号/行高、搜索、筛选、新建工作区、底部费用卡与账户区。
- 窗栏提供布局切换按钮，可随时恢复经典布局；选择本地持久化。
- 仅 macOS 桌面修改；其他平台保持现状。

## 验收

1. 同窗口、同侧栏宽度、同字号、同展开状态，首屏多显示至少 4 条完整会话。
2. 切换按钮在紧凑/经典之间往返，重启后保持。
3. 新建会话、搜索、自动化、插件、更多、工作区筛选/新建、账户与费用入口均可达。
4. 会话行字号、工作区树层级与底部费用卡不变。
